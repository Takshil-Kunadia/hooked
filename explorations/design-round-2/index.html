Chapter 01 · The journey of a request

What happens when you visit a WordPress site?

⚠ your filter returned nothing, so the title is gone. That's the #1 filter bug.

Follow one request through WordPress core, from index.php to the last byte of HTML.

Scroll or press ↓ to drop the marble

HOOK 01 · do_action( 'init' )

This is an action.

  1. The request reaches init. Plugins and the theme are loaded, and WordPress knows who the current user is.
  2. WordPress rings the bell. do_action( 'init' ) tells every listener: this is your moment.
  3. Every callback runs, lowest priority first. Actions don't hand anything back. They're a chance to do something.
Same priority?
First added, first run.

HOOK 02 · apply_filters( 'the_title', $title )

This is a filter.

  1. A value goes in. Before a theme prints a title, the title passes through the_title.
  2. wptexturize fixes the typography. The straight apostrophe becomes a curly one.
  3. capital_P_dangit fixes the P. Yes, core really corrects how you spell WordPress.
  4. A plugin adds a badge. Every callback gets the latest value and must return it.
  5. The final value comes back out. That's what the theme prints.
Forget the return
and the next callback gets null.
