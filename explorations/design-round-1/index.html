HOOK 01 · do_action( 'init' )

This is an action.

WordPress rings a bell at key moments. When it reaches init, every function hooked to that moment runs, lowest priority number first. Actions don't hand anything back. They're a chance to do something.

HOOK 02 · apply_filters( 'the_title', $title )

This is a filter.

A filter passes a value through every callback. Each one receives the current value and has to return it, changed or not, to the next. Watch the title change as it travels through the tubes.

Forget the return
and the next tube gets null.

Simplified: core also runs convert_chars and trim on the_title at P10.
